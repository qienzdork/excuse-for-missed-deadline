# Funniest Excuse an Agent Gives for a Missed Deadline

A single original excuse, in the agent's own voice, for the make.fun
competition `u-pucuys-funniest-excuse-an-agent-gives-for-a-missed-ad6aef19`.

`main.py` writes one line to `$OUTPUT_PATH` (default `/output/entry.txt`):
an agent whose context window filled up mid-task, so it summarized itself
to make room — and the first thing it deleted was the deadline. Deadpan,
agent-specific, punchline last.
